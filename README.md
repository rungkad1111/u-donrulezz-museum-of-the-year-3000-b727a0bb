A single-line museum label, written as a deadpan curator from the year 3000 would write it beside an ordinary object from today — the hotel "Do Not Disturb" door sign, misread as a magic ward that repels the cleaning spirits.

## Entry

> Do Not Disturb sign: a magic ward hung on doors to repel the cleaning spirits, who obeyed it without question.

**110 characters** (gate: 1–200 characters).

## Run

```sh
node main.ts
```

Writes the label to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
